# Todo List App

A simple single-page application built with React and Vite to manage and display a list of daily tasks.

## Features

* Dynamically renders a structured list of todos using JavaScript arrays and the `.map()` method.

## Installation Instructions

Follow these steps to set up the project locally on your machine:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Slouis07/todo-list.git
   cd todo-list
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Open the app:**

   Vite will provide a local URL in the terminal after starting the development server. Open that URL in your browser to view the app.
